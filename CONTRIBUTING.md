# Contributing

The Ferrite team maintains package sources, manifests, and their checksummed index here. We accept issues for defects and proposals. The team handles implementation and release.

To report a defect or suggest a change, open an issue in this repository. Say what you expected, what happened instead, and the smallest steps that reproduce it. A pull request opened here is closed with a pointer to this file, and the idea in it is welcome as an issue.

Report a security problem privately to security@ferrite.cloud, as `SECURITY.md` describes, and not in a public issue. Problems with the hosted platform belong in the issue tracker at <https://github.com/iGentAI/ferrite-cloud/issues>, or can be sent to info@igent.ai.
