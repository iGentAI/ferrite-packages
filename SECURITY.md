# Security

Report a suspected vulnerability in this repository, or in the hosted Ferrite platform, by email to security@ferrite.cloud. Please do not open a public issue for it.

A useful report says what you found, gives the steps or the request that shows it, and names the application or address involved if there is one. Please give us the opportunity to fix the problem before you describe it publicly, and do not read, change or delete data that is not yours while you test.

Questions that are not about security go to the issue tracker at <https://github.com/iGentAI/ferrite-cloud/issues> or to info@igent.ai.
